# 中文校对

1. 读稿：Word 用 office_read paragraphs（长文分段读完），其他文件用 read_document，文字直接用。
2. 机械检查：office_read proofread（Word 文件给 path，文字给 text），会找出半角标点、括号引号不成对、重复字词、常见错别字、数字和日期写法不统一、全角数字等。逐条看，误报的去掉。
3. 自己再通读一遍，查工具查不出的：
   - “的、地、得”和易混词（“截止/截至”“权利/权力”“必须/必需”等）；
   - 搭配不当、成分残缺、语序问题；
   - 前后不一致：人名、单位名、数字、日期、术语、编号；
   - 事实性存疑处只提示，不替用户改。
   不改作者的风格和观点；用户只要校对时，不顺手润色。
4. 交付方式：
   - Word 文件：word_document revise 在文件上用修订模式改（每条一个 edit：find 写原文里一段唯一的文字，replace 写改后，comment 写理由），存疑的只加批注不改；用户在 Word 里逐条接受或拒绝。原文件要保留时给 output 另存。
   - 文字：列表给出“原文 → 改为 → 理由”，再给改后全文。
5. 回复里按类别统计改了多少处（错别字、标点、数字、前后不一致、语句），列出只加了批注、需要作者决定的地方。
