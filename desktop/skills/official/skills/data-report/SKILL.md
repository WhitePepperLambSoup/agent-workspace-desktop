# 表格数据分析

1. 读数据：xlsx 用 read_document，csv 或 JSON 表用 query_table（也可以 read_file 读 csv 文本）。数据大时可以在暂存沙箱里用 run_sandbox 跑 Python 计算，代码直接写在命令里（python -c），不要为计算在用户的文件夹里新建脚本文件；万一建了，结束前删掉。先说明读到了什么：几张表、多少行、有哪些列、各列的类型和缺失值。
2. 明确问题：用户要看的是什么（趋势、排名、占比、对比、异常）。没说就做最常用的：总量、按主要维度分组汇总、Top 5、环比或同比（有时间列时）。
3. 计算：
   - 数字自己核算一遍，汇总值和明细对得上；
   - 遇到合并单元格、单位不一致、重复行时先说明怎么处理的；
   - 不要编造数据里没有的数字。
4. 输出：
   - 结论先行：3～5 条带数字的结论；
   - 汇总表：用 create_xlsx 生成新的 Excel（汇总表放第一张，必要时用公式让用户能核对），存到工作区 `reports/`；不要改动用户原来的表格；
   - 图表：需要时写一个 HTML 文件（内联 SVG 画柱状图 / 折线图 / 饼图，不依赖外部库），存到工作区 `reports/` 并给出路径。
5. 告诉用户结论的局限（样本少、时间短、缺字段等）。
