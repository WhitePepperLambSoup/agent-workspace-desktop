# 邮件与会议邀请

1. 读邮件：office_read email 读 .eml / .msg（发件人、时间、正文、附件列表）。一串往来邮件按时间顺序理清：谁提了什么要求、截止时间、还没回答的问题。
2. 总结：三五行写清对方要什么、什么时候要、需要用户决定什么；附件内容要看时，email_files save_attachments 存出来再用 read_document 读。
3. 起草：
   - 先问清用户的立场和要点（同意、拒绝、要补充什么），不替用户做承诺、报价或答应期限；
   - 结构：称呼 → 一句话回应来意 → 正文（分条写要点）→ 需要对方做什么、何时 → 致谢与署名；
   - 语气按对象调整：上级和客户正式、同事简洁；中文邮件不用翻译腔，英文邮件用简短的句子；
   - 主题写清事由（回复时保留“Re:”）。
4. 生成文件：email_files draft 写成 .eml 草稿（reply_to 填原邮件时会带上引用和回复关系，attachments 可附文件夹里的文件）。只生成草稿，不会发送：告诉用户双击文件，在 Outlook 里检查后自己点发送。
5. 会议邀请：email_files invite 生成 .ics（标题、开始时间、时长或结束时间、地点、说明、参会人邮箱、提前提醒分钟数）；时间按这台电脑的时区。双击文件可加入 Outlook 或系统日历，参会人要用户自己发送。
6. 邮件里的链接、二维码、要求转账或提供账号密码的内容，提醒用户核实来源（可以用 scam-check 技能）。
