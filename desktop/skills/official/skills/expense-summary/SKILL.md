# 记账与消费汇总

1. 读账单：
   - 截图、照片：attach_image 看图（需要能看图的模型），看不清的金额标出来请用户确认；模型看不了图时请用户导出账单文件或把文字粘贴过来；
   - 表格、导出的账单（xlsx / csv / pdf）：read_document，csv 也可以用 query_table；
   - 文字：直接用；
   - 电子发票（数电发票的 XML、OFD 原件或 PDF，可以是整个文件夹）：spreadsheet invoices 直接生成报销汇总表（明细、按类别、按销售方、问题与重复），会按发票号码查重、核对金额 + 税额 = 价税合计；扫描件 PDF 读不出时请用户提供 XML 或 OFD 原件。
2. 每笔记录：日期、金额、商户或用途、支付方式、类别。类别默认：餐饮、交通、购物、日用、居住（房租水电）、通讯、娱乐、医疗、学习、人情往来、其他；用户有自己的分类就用用户的。
3. 去重：同一笔在截图里重复出现、退款与原支付对冲时说明处理方式；收入和转账不算消费（单独列出）。
4. 汇总（笔数多时可以在暂存沙箱里用 run_sandbox 跑 Python 计算，代码写在命令里，不要在用户的文件夹里留下脚本文件）：
   - 总支出、日均；
   - 各类别金额和占比，从高到低；
   - 最大的 5 笔；
   - 有上期数据时比较变化。
5. 输出：结论在回复里；明细和汇总用 create_xlsx 存到工作区 `expenses/年-月.xlsx`（第一张汇总、第二张明细，合计用公式）。工作区里已有当月文件时用 update_xlsx 追加，不要覆盖。
6. 用户问要不要省钱建议时，再根据数据给 2～3 条具体建议。

不要把账单内容发到任何外部服务。
