# 文献综述

1. 先确认：主题和范围（年份、领域、只要期刊还是也要预印本）、用途（开题、综述论文、组会汇报）、要多少篇、引文格式（没说就用 GB/T 7714 数字制；英文论文用 APA）。
2. 检索：paper_search 至少检索三轮——
   - 用户的原话；
   - 英文关键词和同义词（中文主题一定要再用英文检索一次，反之亦然）；
   - 从最相关的几篇的题目和关键词里挑新词再检索。
   需要最新进展时 sort=date；要经典文献时用默认相关度排序并看被引次数。
3. 筛选：去掉题目不相关、撤稿（retracted）的；同一工作的预印本和正式版只留正式版。留下的用 reference_library action=add 存进文献库（以后写作和导出都用它）。
4. 精读：有全文 PDF 的用 read_paper（先 outline 再读需要的页）；只有摘要的如实说明只看了摘要。不编造没读到的方法、数据或结论。
5. 整理：用表格写出每篇的 作者-年份、研究问题、方法、数据、主要结论、局限。数字只写原文里有的。
6. 综述：按主题或方法分组（不是逐篇罗列），写出各组的共识、分歧和空白，最后写可以做的研究问题。每个论断后面标引用；引用读过的页用 [p. N](论文.pdf#page=N)。
7. 交付：
   - 参考文献表用 reference_library action=format（用户要的格式）；
   - 写 LaTeX 的用 export_references 导出 .bib，正文用 \cite；
   - 写 Word 的把格式化的参考文献表放在文末。
8. 写完用 check_references 核对一遍参考文献表，有对不上或撤稿的告诉用户。
