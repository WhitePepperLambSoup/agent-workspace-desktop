# 会议纪要

1. 拿到原文：
   - 录音文件：meeting_transcribe 转成带时间的文字稿（用 设置 → 语音 里选的转写服务，长录音自动分段，稿子存在录音旁边）；提示没有选转写服务时，请用户去设置里选，或提供会议软件导出的文字稿，不要凭印象写；
   - 文档：read_document；文字直接用。
   原文很长时分段读完再写，不要只看开头。
2. 纪要结构：
   ```
   # 会议纪要：主题
   时间 / 地点 / 参会人（原文里有才写）
   ## 讨论要点（按议题，每题 2～4 条）
   ## 决议
   ## 待办事项
   | 事项 | 负责人 | 截止时间 |
   ## 待定问题
   ```
3. 规则：
   - 决议和待办只写原文里明确说了的；负责人、时间没说的写「未明确」；
   - 口语整理成书面语，去掉重复和寒暄，但不改变意思；
   - 不同人观点不一致的地方如实写分歧。
4. 输出：回复里给纪要全文；用户要文件时用 create_docx 存到工作区 `meetings/日期-主题.docx`。
   要正式的公文格式纪要时，用 word_document create_official（kind 为 纪要，写出席、请假、列席人员）。
5. 待办里有明确日期时，问用户要不要提醒：连接了手机时可以用 phone_task 请手机在日历里加提醒（手机上会先问用户）；也可以告诉用户在「定时任务」里设一个到时提醒的任务。下次会议时间定了的，可以用 email_files invite 生成会议邀请（.ics）。
