# 论文精读

1. read_paper part=outline 看标题、DOI、各节起始页、图表标题、摘要。扫描版（没有文字层）如实说明读不了文字，请用户换文字版。
2. 按用户目的读：
   - 只要大意：摘要、引言最后一段、结论；
   - 要方法：方法一节全文，公式按原文转成 LaTeX；
   - 要复现：方法、实验设置、参数表、数据来源、代码链接都要找到；
   - 回答具体问题：先 part=find 找相关段落，再读那几页。
3. 讲解：
   - 一句话说清它解决什么问题、用了什么办法、结果如何；
   - 方法用自己的话分步骤讲，必要的公式保留并解释每个符号；
   - 实验：数据集、对比方法、主要数字（只写原文里的）；
   - 局限和适用范围：作者自己说的和你看出来的分开写。
4. 每个具体说法后面标页码：[p. N](论文路径.pdf#page=N)，用户点了就打开到那一页。
5. 用户要存档时，把笔记写成 Markdown 存到 `notes/论文简称.md`；用 paper_lookup 用 DOI 查到元数据，reference_library action=add 存进文献库。
