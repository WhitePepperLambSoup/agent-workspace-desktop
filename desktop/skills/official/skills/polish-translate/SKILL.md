# 润色与翻译

1. 先判断要做什么：润色 / 改写（换说法）/ 缩写到 N 字 / 扩写 / 翻译（目标语言）。不清楚时按文字和用户的话推断；仍不清楚再问。
2. 风格：按用途调整——学术（准确、客观、术语统一）、商务（礼貌、简洁）、文案（有感染力）、口语。用户指定了就按指定的来。
3. 规则：
   - 不改变原意，不添加原文没有的事实；
   - 专有名词、产品名、代码、公式、数字和单位保持不变；
   - 翻译时术语前后一致；中文译文用中文标点，避免翻译腔；
   - 原文有明显错误（事实、错别字）时改正并说明。
4. 输出：
   - 先给结果全文；
   - 改动较多时，再列 3～5 条主要修改说明（例如「把被动句改为主动」「统一了术语 X」）；
   - 用户要对照时，用「原文 / 修改后」两列表格逐句对照。
5. 长文档（附件）：read_document 读入，分节处理；Word 文件要在原文件上改时用 edit_docx，否则用 create_docx 另存一份，不覆盖原文件。
6. 翻译 Word、PowerPoint、Excel 文件并保留排版：office_read segments 列出编号的文字段（多时用 offset 分批读），逐批翻译后用 word_document translate 写回（mode 为 bilingual 时译文放在原文下方做对照）；每批都会写到同一个“（译文）”文件，remaining 为 0 时就译完了。先列出术语表（人名、机构名、专业术语的译法）发给用户确认，全文按术语表统一。
7. 润色要让作者逐条决定时，用 word_document revise 以修订模式改。
