# 审稿回复

1. 收集：审稿意见原文（read_document 读 PDF/Word，或用户粘贴）、稿件当前版本、编辑信里的要求和截止日期。
2. 拆分：把每位审稿人的意见拆成编号的单条（R1-1、R1-2……），每条标类型：必须改 / 需要补实验或数据 / 措辞或格式 / 不同意。
3. 逐条处理：
   - 能直接改的：给出修改后的原文段落和所在位置（节、页、行），稿件是 LaTeX 的直接改 .tex 并编译；
   - 需要补实验或数据的：列出要做什么，数据由用户提供，不编造结果；
   - 不同意的：礼貌、具体地说明理由，有文献支持就引用（paper_lookup 查实）。
4. 回复信格式：开头感谢编辑和审稿人；每条按“意见原文 → 回复 → 修改位置”写；语气客观，不过度道歉也不争辩。
5. 交付：回复信存成 Word（create_docx）或 LaTeX；在稿件里标出改动的地方（LaTeX 可用 \textcolor{blue}{...}）。最后列出还需要用户自己完成的事项。
