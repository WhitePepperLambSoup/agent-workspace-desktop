# 学习卡片与错题整理

1. 读材料：文档用 read_document；照片和截图里的题目用 attach_image 看图（需要能看图的模型；看不清的地方标出来请用户确认，模型看不了图时请用户把题目打出来）。
2. 按用户要的形式输出：
   - 知识点提纲：章节 → 知识点 → 一句话解释 + 例子；
   - 问答卡片：每张「问：…」「答：…」，一张卡只考一个点，答案简短；
   - 练习题：选择、填空、简答混合，题后附答案和解析；难度从易到难；
   - 错题本：原题 / 我的错误答案（用户给了才写）/ 正确答案 / 错因分析 / 同类题 1 道。
3. 数学、物理、化学公式用 LaTeX 写（行内 $…$，独立公式 $$…$$），对话里会排版显示。
4. 保存：写进工作区 `study/科目-主题.md`；用户要长期复习时，问要不要加入知识库，同意后用 knowledge_add，以后可以直接搜。
5. 内容以材料为准，补充的拓展知识要标明「补充」。
