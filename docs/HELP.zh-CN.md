# 使用帮助

[English](HELP.md)

## 开始使用

第一次打开时，程序会依次让你设置两项内容。

1. **模型**：选择服务商，粘贴 API 密钥，点"连接并保存"。程序会先用这个密钥试连一次，连通后才保存为默认。DeepSeek、通义千问、Kimi、智谱在国内可以直接使用；OpenAI、Claude、Gemini、Grok 需要能访问对应服务的网络。如果在本机运行模型，选 Ollama、LM Studio、llama.cpp 或 vLLM，不需要密钥。
2. **工作文件夹**：Agent 只在这个文件夹里读写文件，修改前会询问。不确定选哪个时，用"使用默认文件夹"（在"文档\Agent Workspace"下）。之后可以随时添加其他文件夹。

密钥保存在 Windows 凭据管理器中，不写入任何文件。

## Windows 提示"已保护你的电脑"

正式版目前没有代码签名证书，SmartScreen 会提示。点"更多信息"，再点"仍要运行"。可以把安装包的 SHA-256 与发布页列出的值核对：

```powershell
Get-FileHash .\AgentWorkspace-Setup-1.0.0.exe -Algorithm SHA256
```

## 连接模型失败

| 提示 | 处理 |
| --- | --- |
| 服务商拒绝了这个密钥 | 确认密钥完整、未过期，并且属于所选服务商。 |
| 账户余额或额度不足 | 到服务商网站充值。 |
| 服务商限流 | 稍后再试，或在设置里换一个模型。 |
| 连接不上服务商 | 检查网络。使用代理时要开启系统代理，程序会沿用系统代理设置，暂不支持 PAC 自动配置脚本。 |
| 服务商找不到这个模型 | 检查模型名称。服务商改名后，在"设置 → 服务商与运行时"里修改。 |

任务中途失败时，对话里会说明原因并提供"打开设置"或"重试"。

## 关闭窗口后还会运行吗

有任务在运行、有计划任务或开着手机连接时，关闭窗口会询问：在后台运行，还是退出。选择在后台运行后，程序图标留在任务栏右下角的通知区域，点击图标可以重新打开窗口。

可以在"设置 → 后台运行"里修改：

- 关闭窗口时的默认行为；
- 开机时启动并在后台运行；
- 任务运行时不让电脑睡眠（默认开启，仅阻止自动睡眠，合上笔记本盖子仍会睡眠）。

计划任务只在程序运行时才会执行。

## 花费

设置里可以查看每月账单，并设置单任务和每月的花费上限。输入框下方会根据你最近的任务估算费用。金额按公开价目表计算，以服务商账单为准。

## 很长的任务

一个任务最多可以连续运行一天。断网或连接断开时，程序会等待并自动重试，最多等约 7 分钟；连接没有动静超过 5 分钟也会重新连接。本机模型不受这个时间限制。任务 5 分钟没有动静或失败时会发通知。

默认的单任务花费上限是 50 美元，到达后任务会停止，发送“继续”可以接着做。这个上限可以在设置里修改。

## 外部内容里的指令

网页、文档或命令输出里如果有像是在指挥 AI 的文字（例如“忽略之前的指令”），对话里会提示：这一轮接下来的每一步都会先问你，这个对话已允许的操作会被撤销，也不会写入记忆和知识库。下一条消息开始恢复正常。这是按常见说法检测的，不能保证拦下所有情况。

## 手机连接

需要安卓版 2.5.0 或更高版本。打开"设置 → 手机连接"，用手机扫描二维码。手机和电脑要在同一网络，或都在 Tailscale 上。如果 Windows 防火墙拦截，页面会提示并提供放行按钮，Windows 会要求确认。

## 数据和备份

所有数据都保存在这台电脑上：

| 内容 | 位置 |
| --- | --- |
| 对话、知识库、记忆、备份 | `%LOCALAPPDATA%\AgentWorkspace` |
| 窗口设置、日志、崩溃转储 | `%APPDATA%\agent-workspace-desktop` |
| API 密钥 | Windows 凭据管理器 |

程序每天自动备份一次数据库，保留最近 10 份。"设置 → 数据与备份"可以查看占用空间、立即备份、从备份恢复。恢复时程序会重启，被替换的数据库保留在数据文件夹里，文件名含 `before-restore`。

如果数据库损坏，对话页会显示恢复选项：从最近的备份恢复，或用空数据库重新开始。两种方式都不会删除损坏的文件。

卸载程序不会删除这些数据。要彻底清除，卸载后手动删除上面两个文件夹。

## 更新

程序每天检查一次新版本，只读取发布页，发现后在窗口右下角提示，点击才下载。可以在"设置 → 关于与更新"里关闭自动检查。便携版不能自动更新。

## 界面卡顿

- 关闭 3D 背景：设置 → 外观 → 对话背景，选择"流动色块"。
- 确认 3D 画质是"标准"。"高画质"适合有独立显卡的电脑。
- 关闭边缘折射：设置 → 外观。

没有 GPU 加速时，程序会自动使用流动色块。

## 安全提示

沙箱是审查边界，不是操作系统级隔离：沙箱里的命令仍有当前用户对其他文件和网络的访问权限。不要在不信任的代码仓库里使用 YOLO 或完全访问模式。详见 [SECURITY.md](../SECURITY.md)。

## 反馈问题

在"设置 → 关于与更新"中：

- "导出诊断信息"生成一份报告，密钥会被遮盖，不包含对话内容；
- "反馈问题"打开 GitHub 的新问题页面，附上诊断报告更便于定位。

报告里不要放 API 密钥、私有代码或个人信息。安全问题请通过仓库 Security 页的 "Report a vulnerability" 私下报告。
